# PhytoFrontiers submission package

Prepared 10 September 2026 for the submission of:

> Cultivar-dependent transcriptional responses of lychee to *Peronophythora litchii*: a registered genome-wide analysis

## Recommended upload set

Use the journal's streamlined initial-submission option and upload these files in PhytoFrontiers ScholarOne:

1. `PhytoFrontiers_initial_submission.pdf` — designate as **Main Document**. This is the complete reviewer file: 12-point Arial, double-spaced, continuously line-numbered, with first author/journal/page headers, all four tables after Literature Cited, and all six figures with their captions on the same pages.
2. `PhytoFrontiers_cover_letter.docx` — designate as **Cover Letter**. Its significance statement is five sentences, within the APS requirement of three to five sentences.
3. `supporting_information/PhytoFrontiers_eXtra_figures.pdf` — designate as **e-Xtra**. It is one PDF containing a cover page and Figures S1–S3 with captions.

Do **not** also upload the Word manuscript or six separate main figures at initial submission when using this single-PDF option; doing so would duplicate material in the generated proof. Review the ScholarOne proof page by page before approving it.

Retain `PhytoFrontiers_manuscript.docx` for revision, because APS requires editable source files after initial review. It also contains the tables, figures, and captions. The `figures/` directory contains separate production assets for a later revision/final submission: APS-preferred 300-dpi LZW TIFF files plus vector-PDF backups. If ScholarOne requests separate TIFF figures, paste the corresponding caption from `FIGURE_CAPTIONS.txt` into each caption field. Do not upload a PDF figure separately unless its caption has first been placed inside that PDF, as instructed by the portal.

Do not upload `README_submission.md`, `submission_metadata.md`, `reviewer_selection_template.md`, `FIGURE_CAPTIONS.txt`, `prepare_submission.py`, `PhytoFrontiers_initial_submission.tex`, `VALIDATION_REPORT.txt`, or `UPLOAD_FILE_MANIFEST_SHA256.tsv`; these are preparation and verification aids.

The complete machine-readable supplement and reproducibility archive is publicly available at <https://zenodo.org/records/22436625>. This open CC BY 4.0 Zenodo record contains `lychee_unified_manuscript_supplement.zip` (19,167,242 bytes; MD5 `a7dce65e381f77ca365820311704b736`), which matches the local archive. The single e-Xtra PDF is therefore a concise journal-hosted supplement, while the Zenodo record supplies Tables S1–S18, figure source data, code, workflows, tests, metadata, and environments to editors and reviewers.

## Current APS requirements used

- Initial manuscripts may be uploaded as one PDF designated Main Document; this package uses that route and retains Word for revision.
- The reviewer PDF uses US letter pages, 12-point Arial, double spacing (including tables and captions), line numbers, and a header identifying the first author, journal, and page.
- Research abstracts are limited to 250 words in one paragraph.
- Research papers use Materials and Methods, Results, Discussion, Acknowledgments, and Literature Cited in that order after the introduction.
- Tables are placed after Literature Cited; editable versions are preserved in the Word source.
- For the streamlined PDF, figures and legends are embedded and kept together. If separate files are later requested, composite panels must be preassembled and each TIFF/JPEG/EPS caption pasted into the ScholarOne caption field.
- e-Xtra material is consolidated into one PDF and contains no password protection, active content, or macros.
- In-text references use author–year style; Literature Cited is alphabetized and lists all authors.
- A cover letter is required and should explain significance in three to five sentences.
- The submitting and corresponding author must have an ORCID.
- At least two recommended reviewers are required.
- AI tools used to improve writing must be described in Acknowledgments; AI-generated image manipulation is not allowed.

## Cost and access

PhytoFrontiers is gold open access. The current APS listing for Research articles is US$2,550 for an APS member or US$2,678 for a nonmember for the first 12 published pages, then US$144 or US$215 per additional page, respectively. Color figures are included. e-Xtras are US$80 per uploaded file. Fees apply after acceptance and can change, so confirm them in the live instructions before submission. APS lists advance waiver requests only for eligible corresponding authors residing in low- or lower-middle-income countries.

## Rebuilding and integrity checking

Run `python3 prepare_submission.py` from this directory. XeLaTeX, Pillow, and python-docx are required. The script checks the title and abstract limits, expected citations, four main tables, six source figures, and figure legends, then rebuilds the all-in-one PDF, editable Word files, e-Xtra PDF, production TIFF/PDF figures, caption aid, validation report, and SHA-256 manifest. The manifest intentionally lists only the three recommended initial-upload files.
