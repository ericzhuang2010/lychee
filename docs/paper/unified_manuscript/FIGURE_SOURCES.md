# Figure source and regeneration note

The replacement figures are generated by `build_figures.py` from frozen TSV
outputs already present in this repository. No values are transcribed into the
plots by hand, and the script stops if any headline count differs from the
analysis outputs.

Run from the repository root:

```bash
python3 docs/paper/unified_manuscript/build_figures.py
```

Outputs are written as vector PDF and 300-dpi PNG files under `figures/`.

## Interpretation guardrails encoded in the figures

- Cohort library counts are 12, 36, 12, 12, and 12; cohort roles are displayed
  separately rather than pooled.
- DTU discovery uses `stage_gene_q` and `usage_interaction_difference`. Primary,
  generic-transfer, and exploratory follow-up results remain separate.
- The four DTU events supported in PRJNA1090613 are labelled exploratory and are
  never counted as primary external support.
- “Cross-context support” is not presented as direct replication or biological
  validation.
- Missing InterPro and small-RNA references are reported as evidence limitations,
  not as biological null results.
