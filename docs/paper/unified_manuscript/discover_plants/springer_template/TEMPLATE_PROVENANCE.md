# Springer Nature LaTeX template provenance

The files `sn-jnl.cls` and `sn-basic.bst` were copied from Springer Nature's official journal-article LaTeX template package, version 3.1 dated December 2024.

- Publisher support page: <https://www.springernature.com/gp/authors/campaigns/latex-author-support>
- Official package asset: <https://cms-resources.apps.public.k8s.springernature.io/springer-cms/rest/v1/content/18782940/data/v12>
- Retrieved: 2026-09-11

The journal's Snapp submission guidance requires LaTeX files to compile with `pdflatex` and to be supplied in a ZIP archive. The generated submission ZIP includes only the class and bibliography-style files needed by the manuscript.
